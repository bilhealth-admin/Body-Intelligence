# BIL v1 visual and UX fidelity closure

The 177 supplied screenshots are a binding interaction and layout reference,
not a source of third-party branding, artwork, advertising, or proprietary
copy. BIL preserves its own identity, privacy model, medical safety boundaries,
Body Twin, explainable intelligence, connected-health work, and verified data
flows.

The generated manifest and coverage matrix live under
`artifacts/release/visual_closure/reference/`. Every source image is mapped to
an equivalent BIL route and capability. Repeated screenshots are retained as
separate evidence because they document scrolling, keyboard, selection,
permission, modal, empty, and navigation states.

## Canonical mobile system

- Platform system sans typography with 400/600/700 weights.
- Centered 18sp page titles, neutral light surfaces, and the existing BIL dark
  identity.
- Compact 54dp rows, 68dp bottom navigation, 10–18dp radii, one-pixel dividers,
  restrained shadows, and no decorative haze on utility pages.
- Consistent tabs, sheets, dialogs, inputs, chips, cards, empty/error/loading
  states, safe areas, keyboard avoidance, RTL/LTR, and scalable text.
- Quick add remains the visible path to food search, barcode, voice, meal photo,
  water, weight, exercise, and notes.

## Functional equivalence

Dashboard, diary, nutrition, progress, weekly reports, goals, plans, recipes,
workouts, community, messages, devices, notifications, profile, settings,
privacy, export, help, and subscription routes keep their real repositories and
engines. Missing network, credentials, permissions, licensed media, catalog
data, or physical devices must show an honest usable state; the UI never
fabricates data or claims an unavailable integration.

## Verification boundary

The final gate validates the 177/177 manifest, formatting, focused visual
contracts, golden update and verification, full analysis, full tests, and an
Android debug build. Physical-device, App Store, licensed remote content, and
credentialed cloud checks remain explicit external gates and are never inferred
from mocks.
