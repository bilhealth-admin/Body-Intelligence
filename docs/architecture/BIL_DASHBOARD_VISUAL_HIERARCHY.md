# BIL Dashboard Visual Hierarchy

## Parent baseline

`a08fabbd246bac7d9f52d22103deccd115d986ee`

## Decision

Dashboard surfaces use `PremiumSurfaceLevel.primary`, `supporting`, or `detail`.
The mobile One Best Action command center is the single primary surface. The
mobile Body Twin snapshot is a detail surface. Unspecified surfaces remain
supporting, preserving compatibility.

The hierarchy changes presentation weight only. It does not change content,
ordering, decisions, evidence, commands, localization, persistence, or trusted
truth behavior.
