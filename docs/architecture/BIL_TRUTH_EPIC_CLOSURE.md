# BIL Truth Epic Closure

The Truth Epic closes only through the production consumption boundaries below.

1. Dashboard decisions pass through the trusted Truth adapter.
2. Decision explanations expose bounded provenance and uncertainty.
3. Body Twin output is freshness and integrity gated.
4. Decision outcomes use durable append-only transitions; legacy outcome text
   is not silently promoted into trusted success.
5. Recommendation release requires explicit evidence, reviewed action shape,
   bounded language, and explicit non-recommendation states.

The release boundary does not diagnose, prescribe, infer medication changes,
or add medical meaning. It may release the deterministic action unchanged,
preserve an intentional no-action result, or abstain explicitly.
