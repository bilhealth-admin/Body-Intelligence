The corrected files are in `store_assets/review/apple/v1.0/`. They are five
opaque RGB PNGs at `1170×2532`, with SHA-256 values recorded in that directory's
`manifest.json`. Current App Store Connect visual read-back confirms the same

storefront metadata read back in the final ASC API audit. Premium is sold only
in Egypt, India, Pakistan, and Türkiye, so its attachments use the live Egypt
prices (`EGP 129.99` / `EGP 999.99`) and never invent an unavailable USA/USD
offer. AI Coach and AI Boost retain their valid USA StoreKit reference states.
The test explicitly selects the product being reviewed and rejects these
regressions:

- a monthly attachment with the Annual card checked;
- a CTA price that differs from the selected catalog product;
- a missing store-derived annual badge when the actual monthly/annual StoreKit
  pair has a positive saving;
- a fixed annual percentage that differs from the rounded store-derived saving;
- USD metadata for either Premium product, which is unavailable in USA;
- a fabricated AI Boost discount without store-supplied original-price offer
  metadata.
