# Sapphire community and daily health-history source candidate

Base: 59839c7deb4d1cc860275b9e69578e299cc24d0a; branch: fix/community-sapphire-health-3033.
This is a candidate under active QA, not a claim of signed/native build or store approval.
The prior 30/33 source evidence concerns the parent only and must not be inherited.

Scope: scoped Sapphire theme across Community routes; deliberate chat bubble colors;
peer-identity grouping, exact unread counts, local welcome while first feed loads,
15-second first-load timeout, recoverable QR state; no forced splash delay.
Health: compact daily UI projection from retained evidence; native daily energy
replaces cumulative snapshots, sample-based heart averages appear only for completed
local days; one >100 marker per day with first/peak observed times. This is not a
medical alarm, resting-heart-rate diagnosis, or continuous/time-weighted average.
No background midnight execution is promised; closure is recognized when the view
or sync next runs. Raw records, native queries, permissions, live Watch presentation,
authentication, purchase logic and deployed QR privacy fixes are retained.

The artwork asset initially reuses the repository-owned goals/activity photo at blob
04c85bd8d391b5b869bcdb37895d9f6341ae65ff; its visual fit must be inspected in QA.
It is bundled locally, with no network dependency or embedded tokens.

QA uses every discovered test/ file without portable exclusions or test-name filters.
Performance runs once serially before eight disjoint file partitions. Test-declared
skips, failures, missing local evidence and native/device boundaries must be reported
separately. The full-suite result, not the existence of this document, determines readiness.
