This package closes internal production-metadata gaps without activating external Apple, Google, cloud, billing, or web services.

It declares Arabic and English at the Android and iOS platform layers, preserves RTL support, declares BLE hardware as optional, replaces the default Flutter package description, and adds repeatable production metadata verification.

macOS bundle identifiers, store registrations, release version numbers, provider approvals, signing credentials, billing, cloud deployment, and web support remain deliberate external-phase decisions.
