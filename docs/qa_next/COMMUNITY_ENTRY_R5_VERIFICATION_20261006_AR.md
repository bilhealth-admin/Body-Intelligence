## ما أُغلق في المصدر

### الدخول وطلبات الحساب المتأخرة

يبقى الاسم وحده مطلوبًا، ويُقرأ الملف المحفوظ وBIL Code الصالح من الخادم قبل
إتاحة Community. لا يعدّل onboarding ملفًا موجودًا، ويقبل ملفًا أنشأه جهاز
آخر بدل الكتابة فوقه. لا يغيّر الخصوصية أو discoverability ولا يقبل السياسة
أو ينشئ متابعة أو منشورًا. تبقى المدخلات بعد فشل الشبكة، وDrafts الخاص مستقلًا
عن وجود ملف Community. إصلاح lifecycle خارج Flutter fake clock محفوظ.

أضيف `CommunityOwnerOperation` لربط كل سلسلة async بالحساب والزيارة التي
بدأتها. يحتفظ الاستدعاء المتداخل بشرط الأب وشرطه الخاص؛ إغلاق Composer يلغي
عمليته حتى لو بقي Feed مفتوحًا. انتقال A → B → A يلغي العمل السابق بصورة
دائمة، بينما refresh للحساب نفسه يبقى صالحًا.

أثبت اختبار على SDK المثبّت أن طلب بيانات A قد ينتظر تجديد الجلسة ثم يستعير
token الحساب B قبل دخول transport. يعالج `CommunityOwnerHttpClient` ذلك
بفحص صاحب العملية بعد حلّ token مباشرة وقبل إرسال طلب البيانات، ويشمل
إعادات المحاولة داخل SDK. لا يوقف طلبات GoTrue الخاصة بتجديد الجلسة، لذلك
إغلاق المحرر لا يسجّل خروج المستخدم. يمرّ كل طلب غير تابع لعملية Community
كما كان. لا توجد تعديلات على SDK أو رؤوس Authorization العامة.

يشمل النطاق حفظ المسودات وقراءتها ونشرها ورفع صورها وتنظيفها وreadback
والإيصال. إذا بدأت كتابة metadata ثم ضاع الرد، لا يحذف العميل صورًا ربما
التزم بها الخادم؛ تحذف المحاولة التالية المسارات القديمة التي أكدها الخادم
فقط. الفشل قبل بدء metadata يستطيع تنظيف الصور الجديدة المكتملة للحساب
نفسه. تبقى journals والإيصالات مرتبطة بصاحب العملية وpayload وoperation.

### Composer والصورة الاختيارية

تتحقق مسارات Publish من profile/code الفعليين. إذا لزم onboarding، يعود
المستخدم إلى نصه المحفوظ ويضغط Publish بنفسه مرة أخرى؛ لا يحدث نشر أو قبول
سياسة تلقائي. لا يحجب ذلك Save draft الخاص. تُلغى النتائج المتأخرة للصور
والصوت والـmentions والمشاركين والسياسة عند تبديل الحساب أو مغادرة المحرر.

تعمل مزامنة صورة More الاختيارية داخل نطاق مستقل بعد نجاح الدخول. تشمل
الحماية تجديد الجلسة والرفع وprofile PATCH والرابط المخزّن. تمنع استجابة
قديمة من كتابة URL لاحقة في cache أو عرض SnackBar في زيارة أخرى. فشل الصورة
يبقى غير حاجب بعد نجاح الملف والرمز، ولم تتغير خيارات More القائمة.

### النص والترجمة والإشعارات وإصلاح الانحدار

أصبحت حدود المنشور والتعليق متطابقة مع معنى أحرف PostgreSQL: 1200 Unicode
code points. يحتفظ المحرر بالنص الكامل بعد paste أو الصوت ويعرض خطأ مفيدًا
قبل الكتابة؛ لا يقصه إلى 1200. تشمل الاختبارات astral وcombining وZWJ وحدود
1200/1201 وreadback والمحاولة الآمنة بعد الخطأ. أضيفت النصوص بلغات التطبيق
الـ25 مع الحفاظ على بقية الترجمات.

استعيد عرض طلبات الصداقة وعدد الرسائل الخاصة من readback الإشعارات، دون
قبول طلبات أو تصفير الرسائل عند القراءة. بقيت اختبارات foreground وdwell
وroute coverage والفشل والقراءة الجزئية وتبديل الحساب كاملة. أُصلح overflow
حقيقي في اختيار Profile على شاشة 320×568 ونص 200% بالعربية والإنجليزية.

أظهرت إعادة الانحدار على `86bc948` نتائج فعلية جديدة مجموعها 90 حالة فاشلة
في الأربع مجموعات المكتملة. أُصلحت أسبابها: fixtures مصادقة/profile صحيحة،
مفاتيح Saved وCreator Center ومسار التمرير الفعلي، عقود Drafts الجديدة،
overflow Profile، وfixture النوم الذي عبر تبديل التوقيت الصيفي في Melbourne.
لم يتغير كود النوم أو assertions المدة؛ صارت fixture تستخدم 162 دقيقة
منقضية فعلًا، ونجحت اختبارات الملف في Melbourne وUTC. استُعيدت ملفات

توقف تشغيل أول للشظية 3 أثناء ضغط ذاكرة بعد تشغيل أربعة compilers. حُفظ
كتشغيل مقطوع، ثم أُعيدت الشظية كاملة بنتيجة 1541 ناجحة و31 فاشلة قبل هذه
الإصلاحات. لا يعاد وصف التشغيل المقطوع أو النتائج الحمراء بأنها نجاح.
التحقق التالي يستخدم عاملَي Flutter كحد أقصى مع حدود runner السابقة نفسها.
