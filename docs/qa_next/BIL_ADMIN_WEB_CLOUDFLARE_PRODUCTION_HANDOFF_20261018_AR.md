## المتبقي — لا تُعلن COMPLETE تشغيليًا قبل التالي
1. دخول المالك **بنفسه** إلى عنوان Cloudflare وإكمال Email OTP ثم TOTP. لا يجمع المساعد أو يطلب الأكواد/الرموز/التوكنات. يلزم فحص أن FINANCE & OPS statuses ACTIVE للقراءة بعد AAL2، وعرض قائمة المنح وسجل التدقيق الحقيقيين.
2. إن أرسل Supabase رسالة magic link إلى عنوان خطأ عوض رمز رقم OTP، يلزم مطابقة Auth email template و redirect allowlist مع Origin الجديد عبر المسؤول، دون تعطيل الهوية.
3. اختبار حقيقي، مفوض، من حساب تجريبي مُعَدّ خصيصًا للمنح والسحب والإيصالات وتكرار/انقطاع الشبكة، مع سجل تدقيق وتأكيد أثر الاستحقاق وعدم تغيير مشتريات المتجر. لا تجرّب على مستخدم أو مراجع متجر حقيقي.
4. اختبارات قراءات ونماذج المشرفين والعضويات والمحتوى وتقارير AI Coach بهوية المالك، ثم اختبار الكتابات الحساسة بعزل بيانات اختبار، مفاضلة الرصد والتدقيق والرجوع. Ops writes تظل LOCKED حتى يثبت كل ذلك، ولا تبديل خفي.
5. قطع انتقال Flutter admin (Codex) لا يحدث إلا بعد نجاح البديل وقرار صريح؛ لا تحذف نظم المراجعة/الحماية داخل الهاتف دون بديل مكافئ ومتوافق، ولا تلمس Codex المحلي ولا main ولا متجرًا.
6. لا توجد شهادة E2E حقيقية للمال أو صلاحيات المالك، ولا شهادة تشغيل iOS37/Android33؛ نجاح 14/14 و16/16 اختبارات نطاق محدد فقط.
