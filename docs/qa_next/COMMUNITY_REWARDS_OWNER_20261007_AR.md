# Rewards / Earn — حدود الحساب والطلبات المتأخرة

## نطاق هذا التعديل

بُني فوق `3851d239d9e31e36d056faee4a22c776888cb47b` على فرع QA المأذون فقط. لا يغيّر سياسة Gold أو AI Tokens أو الأسعار أو Trial، ولا ينشر SQL أو يتصل بـProduction. يظل claim فعلًا صريحًا يملكه الخادم، وليس نتيجة فتح Earn أو محرر المنشور.

## الخلل الذي أعيد إنتاجه

كانت صفحة Rewards تعتمد على generation للتحميل فقط، بلا ربط دائم بزيارة الحساب. أمكن لاستجابة رصيد أو claim متأخرة أن تُقبل بعد تبديل الحساب، بما فيه A→B→A. كذلك ظلت callbacks القديمة قادرة على تنفيذ Claim/Go/Create. تشغيل أول 16 حالة حماية على المصدر السابق أعطى حالتين ناجحتين و14 فاشلة؛ لم يُعتبر التشغيل الأحمر نجاحًا.

## الإصلاح الفعلي

- زيارة ثابتة للحساب تلغى عند تغير الحساب المُسلَّم عبر auth stream، أو الخروج ثم الدخول بالحساب نفسه، أو استبدال repository، أو التخلص من الصفحة. لا تعود الزيارة القديمة صالحة بمجرد رجوع A.
- تفريغ الرصيد المرئي والسجل والمؤشرات عند الإلغاء، ومنع callbacks القديمة من المطالبة أو فتح مسارات أو إعادة التحميل. زر العودة يستخدم مسار Community الآمن.
- ربط reads وclaim وpagination بـ`runForCommunityOwner` الموجود، وفحص هوية العملية بعد كل RPC في أربع دوال Rewards داخل repository. إعادة حل credential بعد token refresh تخضع لحدود النقل الموجودة.
- لا يُلغى token refresh للحساب نفسه؛ اختبار إيجابي يثبت claim واحدًا ثم قراءة الرصيد الفعلي. الاستجابة المتأخرة لعملية التزم بها الخادم لا تؤدي إلى منح ثانٍ أو عكس المنح.
- fixtures القديمة أصبحت تصرح بهويتها الاصطناعية وتدير SDK lifecycle خارج fake clock، مع إبقاء جميع assertions الخاصة بالرصيد وcontrast وlayout وpagination.

## التحقق المحلي المحفوظ

20 حالة جديدة في `community_rewards_owner_test.dart` تستخدم SDK وrepository حقيقيين مع HTTP اصطناعي محلي، وتقرأ صاحب الطلب من Authorization الفعلي في النقل. لا تعتمد على ادعاء fixture باسم المستخدم فقط.

مرّ الأمر المركّز في سبعة ملفات بـ**82 حالة، صفر فشل**، ويضم الحماية الجديدة، Rewards Center، accessibility/700-line ceiling، refresh generation، Earn composer، capture policy، وowner refresh transport. الأمر استخدم Flutter 3.44.6 / Dart 3.12.2 مع `--no-pub --no-test-assets --concurrency 2 --timeout 30s` وTZ=Africa/Cairo. عدم تحميل assets هنا حدّ لبيئة الاستعادة المحلية، وليس تعديلًا لـCI أو دليل مطابقة بصرية.

مرّ `dart analyze --fatal-infos` للملفات المعنية دون findings. سجلّا `rewards_final_focus` و`rewards_final_analyze` المحليان محفوظان مع الأوامر وexit codes. لم تُرفع الخطوط أو أسرار أو بيانات مستخدم.

هذه نتيجة محلية للتعديل؛ يجب قراءة نتائج CI للمصدر الجديد قبل منحه clearance شاملًا. لا تثبت اكتمال Food V2 أو أسطح Community الثمانية أو مطابقة المرجعين أو جاهزية متجر. تبقى نتائج R5 التاريخية منفصلة عن نتيجة هذا SHA.
