# BIL-PLATFORM-READINESS-001

## Purpose

Establish executable, truthful platform capability and release-configuration boundaries before external Apple, Google, cloud, AI, and commerce activation.

## Guarantees

- The local-first core remains available without external services.
- Web never claims native health or native BLE support.
- Cloud, AI, commerce, and store distribution remain configuration-required until verified activation exists.
- Production configuration rejects template application identifiers.
- Cloud activation requires an HTTPS provider endpoint and a public anonymous key.
- Payments require an HTTPS server boundary and verified store activation.

## Exclusions

This package does not add credentials, register store identifiers, enable cloud sync, activate payments, change product features, or modify Dashboard, Nutrition, AI, or database behavior.
