# Product Principles

1. Solve user problems before adding features.
2. Prefer long-term architecture over short-term hacks.
3. Every feature must have measurable user value.
4. No duplicate business logic.
5. Every recommendation must explain 'why'.
6. Science before marketing.
7. Accessibility and responsive design are mandatory.
8. Cross-platform behavior should remain consistent.
9. Protect user privacy by default.
10. Technical debt must be tracked and reduced, not hidden.
