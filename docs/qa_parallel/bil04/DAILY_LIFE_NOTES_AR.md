# BIL-04 — أوامر اليوم وسياق الحياة

## نطاق الاختبار

`test/parallel/bil04/daily_life_commands_test.dart` يضم 28 حالة تنفيذ مع `AppDatabase.forTesting(NativeDatabase.memory())` و`CoachNativeCommandRepository` الفعلي وadapters محقونة. لا يحاكي نجاح commit أو Undo؛ يتحقق من صفوف Drift وسجل عمليات Native بعد التنفيذ والفشل والتراجع. جميع المالكين والبيانات مصطنعة.

| العقد | التحقق الفعلي |
| --- | --- |
| إغلاق اليوم | اليوم الفارغ يبقى مجهول الإجماليات ولا ينشئ وجبات؛ Undo يعيد غياب صف اليوم. |
| الإغلاق وإعادة الفتح | تجمّد القيم الموثقة عند الإغلاق، ثم تعود إلى المصدر الحالي عند إعادة الفتح مع حفظ النوم والملاحظات والنشاط. |
| النوم | الصفر محفوظ ومتميز عن الغياب، وتبقى الملاحظات والخطوات والتمارين وهوية اليوم دون تغيير. |
| ملاحظة اليوم | يستبدل النص فقط؛ Undo يعيد النسخة السابقة وجميع الحقول المرتبطة. |
| اليوم المغلق | يمنع النوم والملاحظة عند وجود أي من علامتي الإغلاق؛ لا تُعامل علامة جزئية باعتبارها يومًا مفتوحًا. |
| سياق الحياة | غياب الموافقة يصير false صراحة رغم القيمة الافتراضية الأقدم في repository؛ حفظ النوع والنص والتاريخ والهوية يُقرأ ويُتحقق منه. |
| Undo لسياق الحياة | tombstone للـUUID نفسه مع revision وsync status صحيحين، وحفظ السجلات الأخرى. لا إحياء لسجل متراجع عنه عند replay. |
| الفشل والصلاحية | rollback فعلي عند فشل قراءة ما بعد الكتابة أو التراجع، وإلغاء المالك، ورفض الصلاحية، أو تعديل يدوي أحدث. |

## الإصلاحات التي كشفها التشغيل

أظهر التشغيل الأول 23 نجاحًا وخمسة إخفاقات حقيقية في ملفي adapter الجديدين المصرّح بتصحيحهما:

1. قُبل النوم/الملاحظة عندما كان `closedAt` موجودًا و`lifecycleState` مفتوحًا؛ يستخدم adapter الآن وجود أي علامة إغلاق.
2. وصف الإيصال الحالة السابقة نفسها بأنها مفتوحة؛ صار مشتقًا من العلامتين.
3. تخطّى `close_day` صفًا بحالة closed وبدون `closedAt`؛ يكمل الإغلاق الصريح العلامة الناقصة الآن. الحالة المطابقة بالكامل تظل بلا إعادة كتابة لكن تمر بقراءة التحقق.
4. لم تتحقق قراءة سياق الحياة من لحظة/مفتاح اليوم المطلوبين؛ صارت تتحقق من الاثنين.
5. لم تتحقق القراءة من UUID المقصود؛ ترفض الآن هوية مختلفة وتُرجع المعاملة.

جرى أيضًا استبدال `Uuid.NAMESPACE_URL` المتقادم بـ`Namespace.url.value` من نفس نسخة الحزمة المقفلة. قيمة namespace والـUUID الناتج لم يتغيرا؛ لم تُرفع نسخة dependency.

## حدود الملكية

اختبارات هذه الوحدة لا تعدّل مستودعات المشروع المشتركة أو schema. توصيل `restoreCoachRecord` وقراءة/إضافة UUID في مستودع سياق الحياة يأتي من overlay الدمج الذي يملكه قائد BIL-04. سجل Native القائم هو صاحب المعاملة، وفحص الاقتراح القديم، وoperation identity، وUndo. لا يوجد سجل ثانٍ.

توثق هذه الاختبارات سلوك adapters؛ أدلة الشاشة والتأكيد والعربية/الإنجليزية في واجهة Coach تُسجل في حزمة اختبار الواجهة المستقلة.
