## العقد ومسار الدمج

    const parser = LocalCoachHealthCommandParser();
    final proposal = parser.parse(
      input,
      locale: locale,
      referenceLocal: referenceLocal,
    );
    final requiresLocalClarification =
        proposal == null && parser.recognizesHealthIntent(input);

الطريقة العامة الجديدة bool recognizesHealthIntent(String input) تميّز عائلة
الطلب الصحي لإرجاع توضيح محلي عندما يرفض parse الطلب. هذه ليست موافقة أو
عملية كتابة. ينبغي استعمال المسار قبل قراءة السياق الشخصي أو الكتالوج العام
أو التحويل إلى نموذج/محلّل آخر. يملك العامل الرئيسي هذا الربط.

لا يغيّر المحلّل صيغ السعرات والماء والوزن الكتابية أو أوامر التنقّل السابقة.
تظل log water وlog weight وopen workouts مثلًا خارج هذه الوحدة. أما show weight
فهي قراءة صحية محدودة، لا كتابة وزن.

كل نتيجة تمر عبر BilToolRegistry.createAction. يظل توليد operationId وحدّ
الثقة للحساب والموافقة وjournal/Undo وقراءة الحالة بعد commit مسؤولية مسار
التطبيق. الكتابة تخرج requiresConfirmation=true؛ لا ينشئ نص المستخدم
clinicianReviewConfirmed، ولا يختلق entitlement أو موافقة استخدام سياق الحياة.

## الصيغ المحددة المدعومة

| القدرة | مثال عربي | مثال إنجليزي |
|---|---|---|
| إغلاق يوم | قفل يومي أمس | close my day yesterday |
| إعادة فتح يوم | افتح يومي بتاريخ 2026-10-05 | reopen my day on 2026-10-05 |
| نوم يدوي | نمت ٧٫٥ ساعة أمس | I slept 7.5 hours yesterday |
| ملاحظة يوم | احفظ ملاحظة أمس: النص كما كتبته | save a note yesterday: literal text |
| سياق حياة خاص | سجل سياق حياتي: النص | save life context: literal text |
| بدء صيام الآن | ابدأ الصيام لمدة ١٦ ساعة | start fasting for 16 hours |
| إنهاء صيام جارٍ | أنهِ الصيام الآن | stop fasting now |
| تعديل هدف الصيام | عدل الصيام إلى ١٨ ساعة | adjust fasting to 18 hours |
| تمرين محفوظ | مشيت لمدة ٣٠ دقيقة أمس | I walked for 30 minutes yesterday |
| معاينة خطة حقيقية | عاين خطة high-protein | preview plan high-protein |
| اقتراح تفعيل خطة | فعل خطة keto | activate plan keto |
| قراءة نوم/نشاط/وزن/قياسات/تغذية | اعرض النشاط خلال آخر ٣ أيام | show weight history last 31 days |
| قراءة التقدم | اعرض تقدمي | show progress last 7 days |
| قراءة جلسة الصيام | اعرض الصيام | show my fasting |
| بحث محتوى محلي | ابحث في المحتوى: النوم | find health content: sleep |

الحدود: النوم 0–14 ساعة؛ الصيام عدد صحيح 1–23 ساعة؛ التمرين عدد صحيح
5–120 دقيقة؛ الملاحظة/السياق حتى 1000 وحدة نصية بحسب عقد التطبيق؛ سؤال
المحتوى حتى 160 وبحد أقصى 3 نتائج. حد القراءة 31 يومًا و31 صفًا. الافتراضي
7 أيام، أو يوم واحد عند تحديد تاريخ. النتيجة لا تحمل calories أو completed
مخترعين لتمرين.

أسماء التمرين المطابقة والمرادفات المحددة تُحوّل إلى معرّفات كتالوج التطبيق
الفعلي، ثم تتحقق coachActivityForExactId منها. يوجد اختبار لكل المعرفات
الـ18 الحالية. الخطط تمر عبر nutritionPathwayForExactId من الكتالوج الحالي؛
high_protein لا يصبح high-protein ولا يستعير خطة أخرى.

## قواعد منع الالتباس

يطابق المحلّل الرأس كاملًا، فلا يختار الفعل الأول أو الرقم الأول من جملة
أطول. close my day tomorrow أو I slept 7 to 8 hours أو عبارتا كتابة في طلب واحد
لا تنتج أي action. يبقى التوجيه المحلي متاحًا لمعظم هذه العائلات عبر recognizer.

التاريخ المقبول واحد فقط عند بداية الرأس أو نهايته: اليوم، أمس، قبل أسبوع،
اليوم الأسبوعي السابق من الصيغ الموجودة في CoachDateResolver، YYYY-MM-DD أو
YYYY/MM/DD، أو يوم + اسم شهر عربي/إنجليزي + سنة. التاريخ المستقبلي أو غير
الصحيح أو المتكرر أو المختلط يرفض. 06/10/2026 وOctober 6 لا يُحوّلان إلى اليوم
الحالي. حساب النطاق يعيد بناء اليوم المحلي بمكوّناته، ولا يضيف 24 ساعة عبر DST.

في الملاحظة والسياق والبحث، النقطتان تفصلان الرأس عن نص حرفي. توحيد الأرقام
والهمزات والمسافات وفحص التاريخ/النفي يقع على الرأس فقط. تبقى الأرقام،
الفواصل، الأسطر، النقطتان الإضافيتان وكلمات أمس/غدًا/لا داخل النص كما هي،
مع إزالة الفراغ الخارجي حول كامل النص. وجود أمر داخل نص الملاحظة لا ينفّذه.

السياق النصي يصبح type=other وuseInInsights=false دون استنتاج نوع طبي أو إذن.
الأسئلة والشرط والنفي والنوايا المستقبلية لا تطابق كتابة. علامة الاستفهام في
رأس كتابة تمنعها؛ لا يمنع الاستفهام داخل نص الملاحظة حفظ النص الصريح.

بدء/إيقاف/تعديل الصيام ومعاينة/تفعيل خطة تخص الحالة الحالية؛ طلب يوم تاريخي
لا يُحذف بصمت كي تتحول العملية إلى الآن.

## صيغ غير منفّذة بهذا المحلّل

- الأرقام بالكلمات، المدى أو البدائل أو كميتان، النوم بمزيج ساعات ودقائق،
  والتمرين بالساعات أو بمدة كسرية.
- الرقم بالفاصلة متبوعًا بثلاث خانات أو أكثر، مثل 7,000، لأنه قد يكون فاصل
  آلاف أو فاصلة عشرية.
- الفترات الحرة أو الأسابيع أو from … to …؛ يمكن طلب عدد أيام صحيح حتى 31.
- أوامر جماعية، أو وصف تمرين لا يطابق الكتالوج، أو اسم خطة وصفي بدل معرّفها.
- تاريخ دون سنة أو تاريخ رقمي يبدأ باليوم، والأحداث المستقبلية.
- توقيت بدء صيام مخصص من نص حر، ومنه startedAt؛ لا يغيّر هذا حد عقد الأداة
  الذي قد يقبل توقيتًا صريحًا موثوقًا من مسار مراجعة آخر.
- استنتاج نوع سياق الحياة أو تشغيل useInInsights من النص.
- البحث بلا فاصل النقطتين، أو بحث عام يتجاوز كتالوج المحتوى المحلي الموجود.

هذه الصيغ تحتاج توضيحًا/واجهة مختصة؛ لا يصح إعلان فهم لغة عامة أو جميع اللهجات.
المحلّل نفسه لا يفتح واجهة ولا يستعمل نموذجًا أو خادمًا.
