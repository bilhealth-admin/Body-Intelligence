# BIL Dashboard Polish 001 — P5

## Scope

P5 consolidates the premium dashboard card language in the shared presentation primitives.

- One semantic dashboard radius.
- One border-width and border-color contract.
- One hover and pressed feedback scale.
- One two-layer elevation contract with an inner highlight.
- Existing dashboard content, sizing, calculations, providers, and synchronization remain unchanged.

## Boundaries

This package changes only `PremiumDesignTokens` and `PremiumSurface`, plus verification assets. It does not change business logic, health synchronization, nutrition calculations, repositories, providers, models, or databases.
