# BIL Dashboard Polish P9-R16

Responsive visual correction package based on the approved P9 implementation.

## Scope

- Removes macro-card overflows across Windows, tablet, and mobile widths.
- Improves macro label legibility and keeps English units to the right of values.
- Uses `kcal` instead of `kcal/day`.
- Moves the watch weekday/date block slightly downward.
- Corrects Body Identity breakpoints and prevents clipped labels/values.
- Isolates analytics values in LTR direction so values render as `94.4 kg` and `+0.3 kg`.
- Adds mobile bottom clearance for the fixed navigation bar and floating action button.
- Allows compact AI cards more text before truncation.

No providers, services, repositories, storage, database, calculations, or AI decision logic are changed.
