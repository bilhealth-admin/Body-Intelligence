# App Store Privacy Draft

Current code-state inventory:

- Tracking: No.
- Third-party advertising: None detected.
- Analytics/crash reporting: Not activated.
- Cloud sync/remote AI/payments/subscriptions: Not activated.
- Health data: accessed only after permission and processed locally in the current configuration.
- Bluetooth health-device measurements: imported only after explicit pairing/permission.

This is not a submission-ready declaration. Reconcile it with Xcode Privacy Report, every embedded SDK, server configuration, retention rules, and the final production build before App Store Connect submission.
