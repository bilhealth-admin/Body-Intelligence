# Privacy Policy Draft — Current Local-First Configuration

This working draft reflects the current configuration only. BIL stores health and nutrition information locally by default. HealthKit and Bluetooth access require explicit user permission. Cloud sync, remote AI, analytics, crash reporting, payments, subscriptions, and uploading HealthKit data are not active in the current configuration.

Before publication, replace owner/contact placeholders, publish at a stable HTTPS URL, add retention/deletion procedures, and revise this policy whenever any external service is activated.
