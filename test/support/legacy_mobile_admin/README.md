# Historical presentation fixtures

These former mobile administration widgets are retained only for existing
regression tests. They are outside `lib`, have no application route, and must
never be imported by application code. Their tests preserve backend contracts,
safe confirmations, receipts and localization while the independent web site
is the only supported operator interface.
